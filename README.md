# ContentPilot AI

ContentPilot AI is a Streamlit web application that generates AI-powered content using the Groq API.

## Features

- Generate AI content
- Select content type
- Choose platform
- Select writing tone
- Enter target audience
- Download generated content

## Technologies

- Python
- Streamlit
- Groq API

## Run

```bash
pip install -r requirements.txt
streamlit run app.py
```
